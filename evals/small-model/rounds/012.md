## The target and why

Round 011 discarded T002 as `too_hard` after three attempts. The curve was 3/3/0/2 → 3/2/0/2 →
3/2/1/2: navigation 3 every time, convention the blocker every time. Three probes solved the code
— one of them in a single line — and **none of them touched `features/menus.md`**, while one wrote
a test unprompted. So the gap is not doc-writing reluctance. It is **doc-location cost**: at 2,539
lines covering every menu in the game, finding the insertion point costs more than the change.

The shape of the problem, from the heading map:

- `## HQ (hq.gd)` runs **~1,300 lines — over half the file** — and is a bag of unrelated tenants:
  the rally-detail panel, hub/boot redirect, field ownership, input branches, **"Adding a
  setting"**, upgrades panel width, map-table costs, and an Android boot notice.
- **"Adding a setting" is a subsection of "HQ".** A probe adding a setting (T007) greps
  `setting` and has to recognise that its answer lives under a heading named after a different
  screen. That is the navigation defect stated exactly.
- `## Menu navigation` is **~525 lines** — a framework, not a screen, sharing a file with screens.

## The fix, and the rule it applies

This repo **already has** the right structure and `menus.md` is the file that escaped it: one
area doc per feature area, each opening with `**Source:**` and `**Tests:**`, each indexed in
`features/README.md` — all three enforced by `tests/headless/test_features_docs.gd`. So this is
not inventing a scheme, it is applying the existing one.

**Acceptance test, fixed in advance at the close of round 011 so it cannot be graded generously
now:** a probe must reach the right section by grepping **the request's own nouns** ("pause",
"settings", "gear", "blur"), without reading an index first. Per §3, splitting into parts that
still need each other's context is the `hq.gd` mistake in documentation form and does **not**
count as progress.

Checked before cutting: **183** references to `menus.md` across the repo (32 of them `# Docs:`
breadcrumbs in `scripts/`), and **zero** anchor-style deep links (`menus.md#...`). So extraction
cannot break an inbound link; the work is to repoint the breadcrumbs whose subject moves.

## Durability — RATCHET

`test_features_docs.gd` gains `test_no_area_doc_grows_into_an_unnavigable_monolith` and
`test_the_oversized_doc_baseline_only_shrinks`:

- **`OVERSIZED_BASELINE`** freezes today's violators at their current size: `overworld.md` 1817,

this one exercised both directions before the round closed.

Line counting matches `wc -l` deliberately (trailing empty segment dropped), so the numbers in
