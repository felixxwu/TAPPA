## Failure causes observed

1. **Hidden coupling across files (×1, severe)** — adding an `EFFECTS` entry
   requires a matching declaration elsewhere, and nothing at the point of use
   says so. Silent at runtime, and **invisible to the test suite**: T001's broken
   change passed every test its rubric named (11/11).
2. **Convention undiscoverable at the point of use (×5, universal)** — *every*
   probe skipped the `features/` update, and every probe that touched a menu
   skipped the nav test. Both rules are stated in `CLAUDE.md`; none of the five
   applied them. A rule that lives only in the rulebook is not reaching a small
   model under context pressure.
3. **`features/` entry stale or misleading (×1)** — `engine-and-transmission.md`
   documented `engine_friction_slope` as **4**; the code says **1.0**, and the
   doc's own worked example was derived from the stale number. The probe did not
   detect the contradiction; it overwrote the doc to match its own change.

## Open defects in the skill (for round 002)

1. **§2.2 seeding cannot work as written.** It says seed the worktree then
   dispatch, but `isolation: "worktree"` creates the worktree *at* dispatch —
   there is no window. Harmless in round 001 only because the tree was committed
   and clean, making HEAD identical to the working tree. **This breaks in round
   002**, which starts with uncommitted changes from this round.
2. **`--fast` exit status can be masked by a pipe.** Piping `run_tests.sh` into
   `grep` reports grep's status; a red run read as exit 0. Always read the
   `TESTS FAILED` / `ALL TESTS PASSED` line, never the piped exit code.
3. **Warm `.godot` copy: validated.** 13 s runs instead of a 300 s cold import,
   no import errors. Keep it.
