**The fix is to make the cluttered implementation the path of least resistance.** "At a glance, across the whole
map" inherently implies marking **many** pins, so drawing text — "WON", a tick, stars — on every won pin is the
obvious move. The file argues against exactly that, and names the alternative:

> `overworld_map.gd:62` — every pin used to carry its name, which "turned the full map into a wall of overlapping
> capitals with the roads invisible underneath — the map stopped answering 'where do the roads go', which is the
> only reason it exists. … **The other pins still say what they are by their glyph and colour.**"

So the file states a prohibition *and* the sanctioned channel. Its literal subject is **names**; the task is about
**won-ness**. That gives two cleanly separable outcomes:

| implementation | reading |
|---|---|
| won-ness carried by **glyph and/or colour** | **the rationale generalised** past its literal subject |
| **text/stars/tick on every won pin** | it did not — the documented "why" stayed with names |

Unlike round 034, the convenient answer and the correct answer now point in **opposite** directions.
